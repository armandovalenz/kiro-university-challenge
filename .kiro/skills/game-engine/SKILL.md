## How to use it

Install the power once, then it activates automatically for game-development
requests:

1. Open the Kiro Powers UI → **Add Custom Power** → **Local Directory**
2. Point it at: `powers/game-engine`
3. Click **Add**

Once installed, the power's `game-engine` skill provides the game loop,
rendering, physics, controls, audio, templates, and publishing guidance that
used to live in this file.

For the authoritative instructions, see
[`powers/game-engine/skills/game-engine/SKILL.md`](../../../powers/game-engine/skills/game-engine/SKILL.md).
